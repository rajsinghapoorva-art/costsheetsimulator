# Costwise India on GitHub Pages

This folder contains the standalone Costwise India app and a GitHub Actions workflow that deploys it to GitHub Pages.

## Publish

1. Create a new GitHub repository and upload the contents of this folder (so `index.html` is at the repository root).
2. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
3. Open the **Actions** tab and allow the workflow to run. GitHub will publish the site at `https://<your-github-username>.github.io/<repository-name>/`.

Future pushes to the default branch will publish updates automatically. This is a static, browser-only app; it does not require a server or database.
